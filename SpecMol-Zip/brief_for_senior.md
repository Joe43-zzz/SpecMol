# 这篇论文在做什么 —— 给学姐的 review 说明（中文）

> 一句话背景：这是一篇投 **ICDE 2027 EAB**（Experiment, Analysis, and Benchmark，下面第 5 节解释）的论文。分子性质预测只是它的 **case study（案例载体）**，真正卖点是一套**评测方法**。

## 先给结论（30 秒版）
这篇论文真正的贡献有三个，**都不是"提了个更强的新模型"**：

1. **FIRE 协议**：一套可复现的"打假"流程，专门回答——当你把一个**冻结的/预先算好的特征**（比如别人预训练好的编码器输出、某个 foundation model 的 embedding、现成的分子描述符）塞进下游模型时，它到底**贡献了真信息（signal）**，还是**只是多塞了一堆参数（parameters）**？它由三个对照组成（见第 1 节）。
2. **一个 7.4-AUC 的数据管线 bug 审计**：作者发现自己代码里一个**"只加单向键"的 loader bug**，光这一个 bug 就能让 BACE 上的成绩凭空摆动 **7.4 个 AUC 点**——比"深度模型 vs 经典方法"的全部差距还大。还横向查了 14 个知名公开仓库做对照。
3. **probe→finetune 修正**：作者证明"冻结特征 + 简单分类头"这种常见评测会**严重低估**一个编码器——冻结的 Uni-Mol 在 ClinTox 上只有 **0.488 AUC（比瞎猜还差）**，但同一个编码器端到端微调后能到 **0.832**。

**关于"没跑赢 SOTA"**：这篇确实没刷榜、没在某个数据集上拿第一。**但这对 EAB 类论文不是减分项，反而正是它要的东西**——EAB 看重的是"对现有方法给出严谨的新洞见 / 新评测方式"，而不是"又一个更高的数字"。本文给出的是一张**严谨的"什么时候有用 / 什么时候没用"地图 + 一串站得住的负向结论**。

---

## 1. "没有特别正向的结果（没跑赢 SOTA）"到底指什么？

指两件具体的事：

**(a) 一张 two-regime map（两区制地图）。** 作者把 8 个任务分成两类：
- **saturated（指纹饱和）**的任务：一个**经典随机森林（RF）**就已经到顶，任何深度/3D 模型都赢不了它（BACE、ESOL、还有 QM7）。
- **non-saturated（未饱和）**的任务：把预训练编码器**正确微调**后能变得有竞争力（FreeSolv、Lipo 等）。

**(b) 一串"null"（零结果）。** 论文最核心的负向发现是：那种"便宜的、把冻结 3D 特征注进 2D 模型"的做法，**在两个区间里都测不到任何提升**——它和它的**"random-pair null"**（把真实 3D 特征换成同样形状的随机噪声）以及**纯 2D 基准线**在**每一个数据格子上都打平**，连用"真·DFT 量子坐标"算出来的高精度几何也救不回来。

> 关键措辞（论文里也是这么写的，建议 review 时注意）：作者**没有**说"3D 完全没用"，而是说"**在我们的统计功效下检测不到提升**（within seed variance / no detectable effect）"——这是诚实的负向结论，不是过度断言。

---

## 2. 为什么没有这种正向结果？（论文给的真实原因）

1. **指纹饱和（fingerprint saturation）**：在 BACE / ESOL / QM7 这类任务上，分子指纹本身已经包含了几乎所有可学信息，RF 一上就到顶，深度模型再花哨也只是追平甚至更差。
2. **预训练目标和下游任务不对齐**：编码器是用"对比学习（contrastive pretraining）"预训练的，这个目标不直接对应"预测某个性质"，所以更复杂的注入路径给了模型更多"满足预训练目标"的方式，却不一定产出对下游更有用的特征。
3. **冻结注入本身不加可测信号**：3D 信息是"冻住"塞进去的（上游编码器不参与下游训练），论文发现这条路径加不进可检测的信号；真正让深度模型变强的是"**把编码器解冻、端到端微调**"——是**容量/训练**起作用，不是注入的几何。
4. **小数据 + 三个种子**：数据集只有约 1k–4k 分子、单一 scaffold 划分，只有 3 个随机种子时，**种子间的波动比效应本身还大**，小差距根本过不了显著性。

## 3. 各数据集上的表现（真实数字）

> 指标：分类是 **AUC，越高越好（↑）**；回归是 **RMSE，越低越好（↓）**；QM7 是 **RMSE↓**；QM9-µ 是 **RMSE↓（Debye）**。
> **⚠️ 务必看懂"深度"这一侧有两种数，差很多：**
> - **冻结探针（frozen probe / 线性评测）**：编码器**冻住**、只在上面训练一个线性头。这是主结果表里 2D-Only/SEG/PBA 报的数，**偏低**（~0.76–0.83）。
> - **微调后（finetune）**：编码器**解冻、端到端训练**，数会**大幅上升**。这正是本文 C2 的核心——冻结探针会严重低估编码器。
>
> 列说明：**RF** = 完全相同测试集上重跑的随机森林（经典强基准）；**deep·冻结探针** = 2D-Only/SEG/PBA 里最好的（线性评测）；**deep·微调后** = 把我们自己的 2D 编码器端到端微调（§IV-D，单 fold-0，n=3，只在 BACE/BBBP/FreeSolv 做了）；**Uni-Mol·端到端微调** = Uni-Mol 自己解冻微调（六个分类/回归任务都有）。

| 数据集 | 指标 | RF（经典） | deep·**冻结探针** | deep·**微调后** | Uni-Mol·**端到端微调** | 谁赢 / regime |
|---|---|---|---|---|---|---|
| BBBP | AUC↑ | 0.814 | 0.831（SEG） | **0.860** | 0.826 | **non-saturated**：微调后深度/Uni-Mol ≥ RF，三者方差内打平 |
| BACE | AUC↑ | **0.906** | 0.780（PBA） | **0.886** | **0.859** | **saturated**：RF 仍第一，但**微调后只差 0.02–0.05，不是大胜**；被甩开的是冻结探针(0.78) |
| ClinTox | mAUC↑ | 0.812 | 0.829（SEG） | —（未做） | **0.832** | **non-saturated/边界**：Uni-Mol FT ≈ RF（Chemprop 0.975 最高） |
| FreeSolv | RMSE↓ | 0.720 | 0.647（2D-Only） | **0.602** | **0.435** | **non-saturated**：微调后深度 / Uni-Mol 都赢 RF |
| ESOL | RMSE↓ | **0.361** | 0.771（SEG） | —（未做） | 0.395 | **saturated**：RF 第一，Uni-Mol FT(0.395) 近第二，冻结图变体(0.77) 远 |
| Lipo | RMSE↓ | 0.643 | 0.873（SEG） | —（未做） | **0.521** | **边界**：Uni-Mol FT(0.521) 赢 RF；冻结图变体(0.87) 远不如 |
| QM7 | RMSE↓ | **~99（组成型）** | ~137（PBA，深度 137–149） | —（未做） | —（无 FT 格） | **saturated**：原子组成主导，RF 大胜 |
| QM9-µ（偶极矩，真 DFT 坐标） | RMSE↓ | **0.845（电荷型）** | 0.880（2D-Only） | —（未做） | —（无 FT 格） | **几何纯任务，RF 仍领先**：最强的"3D 没帮上忙"证据 |

> **一句话纠偏（也是 C2 的点）：** 不要被"冻结探针"那列的低分误导成"深度模型很弱"。**微调之后深度其实很强** —— BACE 微调后 0.886 / Uni-Mol 0.859，已逼近 RF 0.906；FreeSolv、Lipo 微调后直接赢 RF。论文真正的负向结论**不是"深度没用"**，而是两条更精确的话：(1) 在**指纹饱和**的少数任务上（BACE/ESOL/QM7），连微调后的深度也追不平 RF；(2) 那种**便宜的"冻结 3D 注入"**（SEG/PBA 相对 2D-Only）在所有任务上都没测到提升——**有用的是"微调"，不是"注入冻结的几何"**。

> **数字口径说明（review 时可能会问）**：
> - 回归 RMSE 是在"标准化标签"上算的，**不能**和文献里 kcal/mol 的数直接比（论文已注明）。
> - **Uni-Mol FT 的误差棒含义和深度变体不同**：BBBP/ClinTox 的 ± 是真实的 3 种子方差；BACE/FreeSolv/ESOL/Lipo 的 FT 因为工具不支持种子控制，原本是确定性单点（±≈0），作者正在用 **bootstrap** 补真实误差棒（其中 ESOL/Lipo 还在跑，**待确认**）。**均值是可部署的真实点估计、不会变。**
> - QM7/QM9-µ 没有"Uni-Mol FT"这一格——它们是量子压力测试，只对比 RF vs 各深度臂。

## 4. 每个变体是什么、为什么放进来

> 论文里现在用的是描述性新名，括号里是代码/旧代号，方便你对上代码。

**"加 3D 的阶梯"——一个比一个重的注入方式（都建立在同一个图神经网络骨干上）：**
- **2D-Only（V0）**：只用分子的"2D 键连图"，完全不看 3D。**基准线**——所有"加 3D 有没有用"都跟它比。
- **SEG（V2-T5，Static Edge-Gate）**：最轻——把冻结的 Uni-Mol 3D"原子对特征"压成"每条化学键一个权重门"，再喂回图。
- **PBA（T7，Pair-Bias Attention）**：中档——在上面加一层"成对偏置注意力"（类 Transformer），容量更大。
- **APC（T8，Atom–Pair Co-Update）**：最重——让"原子"和"原子对"两条信息流互相更新。只在 QM9-µ 这个纯几何任务上跑（论文诚实标注它**不是**完整版 Uni-Mol attention，只是探针）。

**经典 / 对照基准：**
- **FP-only**：只用"分子指纹"（把分子编码成一串 0/1 子结构向量）接小 MLP，不用图。看"指纹本身"的天花板。
- **RF（随机森林）**：300 棵决策树，输入 Morgan 指纹 + 11 个 RDKit 2D 描述符。**最强的"简单老方法"基准**（Deng2023 配方，30 次随机）——很多论文不报它，本文专门报，结果它常常赢。
- **Chemprop**：学术界标准的有监督图模型（D-MPNN）。reviewer 会期待看到的对照组。

**关于 Uni-Mol（一个预训练好的 3D 分子大模型）的两种用法——这俩的区别是全文关键：**
- **frozen Uni-Mol probe（表里 "Uni-Mol-emb+RF"）**：把 Uni-Mol **冻住**，只取它输出的分子向量喂给 RF。这是**探针**，**不代表 Uni-Mol 自己的真实水平**（冻结时 ClinTox 才 0.488，比瞎猜还差）。
- **Uni-Mol FT（表里 "Uni-Mol (FT)"）**：把 Uni-Mol **整个解冻、端到端微调**。这才是 Uni-Mol 模型**自己的真实战斗力**（同样 ClinTox 涨到 0.832）。
- 把这两行分开列，就是论文的 **probe→finetune 修正**——证明"冻结探针"这种常见评测会严重低估编码器。

## 5. EAB 是啥？这篇为什么算 EAB？

- **EAB = Experiment, Analysis, and Benchmark**，是 **ICDE（数据工程顶会）research track 下的一类论文**（投稿时勾选的"论文类型",不是单独赛道）。
- 它做的是**对现有方法/系统的大规模、受控的评测与分析**。**贡献标准是**："对现有方法给出**根本性的新洞见**，或提出**新的评测方式/基准**"——**不要求**你提新模型，**也不要求**你刷过 SOTA。
- ICDE 对 EAB 还有一条**硬性要求**：**必须公开所有复现 artifact（数据 + 代码 + 管线），零例外**。

**这篇为什么正好是 EAB：**
- 它不提新模型，而是提一套**评测协议（FIRE）** + 一张**受控的"何时有用"地图** + 两个**可迁移的数据管线警示**（7.4-AUC 的 loader bug、probe→finetune 修正）。
- 它的"负向/边界结论"是在**严格匹配协议**（同一划分、同一种子、同一预算）下得到的，并且**全部可从原始 SMILES 重新生成**。
- 这正是 EAB 想要的："严谨地告诉社区——你们以为有用的东西，在受控对照下其实没有可测的提升；而你们忽略的简单基准和数据管线问题，影响比模型选择还大。"

## 这篇为什么适合 EAB + 学姐 review 时最该盯的几个点

**为什么适合 EAB**：贡献是"方法学 + 评测 + 可复现 artifact"，而不是"新模型/刷榜"——完全对口；负向结论 + 强对照 + 全可复现，是 EAB 的加分项。

**review 时最值得你帮我盯的点（这些也是审稿人最可能攻的）：**
1. **统计功效**：很多关键结论是 **n=3 个种子、单一划分**——作者自己都标了"低于我们的 n=9 撤回线"。你觉得"测不到提升"会不会只是**样本太少、功效不够**？措辞是否已经收够（应是"检测不到"而非"不存在"）？
2. **结论的适用范围**：所有"3D 没用"的结论只在**一个非等变的谱图骨干 + 标量/边权注入**上验证过。换个（等变的）3D 模型会不会不一样？正文语气有没有比 caveat 更强？
3. **FIRE 的新颖性**：三个对照单看都是已知的，卖点是"组合 + 系统验证 + 可迁移"。你觉得这对 ICDE 够不够"贡献"？"不限于化学"的说法是当成已证实、还是当成猜想（应是猜想）？
4. **Uni-Mol FT 的可比性**：FT 用的工具不支持种子控制，误差棒语义和深度变体不同（见第 3 节口径说明）。这个对比是否站得住？
5. **数据管线那条线（7.4-AUC bug + split 敏感性）**：这是本文最硬、最不依赖运气的证据。你觉得把它**抬成主线**（而不是当附带发现）会不会更强？
