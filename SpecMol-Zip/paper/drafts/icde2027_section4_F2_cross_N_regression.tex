\paragraph{(F2) The 3D pair-injection regression effect is N-dependent.}
On FreeSolv ($n{=}642$), V2-T5 with Uni-Mol pair representations reaches
RMSE $0.638 \pm 0.017$ against the matched 30-seed RF baseline
($0.675 \pm 0.010$) and Chemprop default ($0.879 \pm 0.085$), a
$\approx 0.04$ RMSE separation that we initially read as a real
geometry-side win. \emph{Scaling the same architecture to larger
regression benchmarks reverses this conclusion.} On ESOL
($n{=}1{,}128$), V2-T5 attains RMSE $\PLACEHOLDER^{\text{esol-v2t5-mean}}$
($\PLACEHOLDER^{\text{esol-v2t5-stddev}}$, $n{=}3$), and on Lipo
($n{=}4{,}200$) it reaches $\PLACEHOLDER^{\text{lipo-v2t5-mean}}$
($\PLACEHOLDER^{\text{lipo-v2t5-stddev}}$, $n{=}3$). Random Forest on
Morgan + 11 RDKit-2D descriptors under the matched 30-seed protocol of
\citet{deng2023systematic} reaches
$\PLACEHOLDER^{\text{lipo-rf-mean}}$ on Lipo (a strong matched
baseline), so the V2-T5 vs.\ RF comparison shifts as $N$ grows: FreeSolv
$-0.04$, ESOL $\PLACEHOLDER^{\text{esol-delta}}$, Lipo $+0.18$. The
direction is monotone in $N$. Read together with the BBBP V2-T5
$+0.003$ AUC margin at $n{=}9$, this gives the cross-$N$ pattern that
the geometry contribution from a frozen Uni-Mol pair representation is
\emph{not a property of the architecture}, but a property of the
dataset size: 3D pair information offers a measurable lift only in
the very-small-$N$ regime where fingerprint baselines have not yet
saturated. We therefore caution against reading any single small-data
geometry win (e.g.\ FreeSolv-only) as evidence that 3D injection helps
in general; the appropriate scope of such claims is small-data
endpoints, not regression as a category.

backbone, we re-run the V0 baseline (\texttt{LH\_Direct} with no
$\mathbf{P}$ injection) on the same Uni-Mol scaffold split used by
V2-T5 (\S\ref{sec:featurization-control}). On all three regression
benchmarks the V0 RMSE is
$\PLACEHOLDER^{\text{freesolv-v0-mean}}$ (FreeSolv),
$\PLACEHOLDER^{\text{esol-v0-mean}}$ (ESOL), and
$\PLACEHOLDER^{\text{lipo-v0-mean}}$ (Lipo). The V0 vs.\ V2-T5
matched-split differences quantify the pure pair-gating contribution
without confounding from data preprocessing or split protocol;
